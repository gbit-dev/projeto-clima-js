# Projeto Clima

Um aplicativo web simples de previsão do tempo desenvolvido com HTML, CSS e JavaScript puro (Vanilla JS).

## Funcionalidades
- Busca da previsão do tempo atual para qualquer cidade.
- Exibição de detalhes da temperatura atual, mínima, máxima, sensação térmica, vento e umidade.
- Exibição da previsão para os próximos dias da semana.
- Tabela com as temperaturas mínimas e máximas atuais das principais capitais do Brasil.

## Tecnologias Utilizadas
- HTML5
- CSS3
- JavaScript (ES6 Modules)
